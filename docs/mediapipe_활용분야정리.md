# MediaPipe 활용분야 정리

## 1. MediaPipe란?
Google에서 개발한 온디바이스(On-device) 실시간 멀티모달 인식 프레임워크.
카메라 영상, 오디오, 텍스트 등을 입력받아 손/얼굴/신체 랜드마크 추출, 객체 인식,
분할(Segmentation) 등을 빠르게 처리할 수 있는 사전 학습 모델과 API를 제공한다.
CPU 환경에서도 실시간 처리가 가능해 별도의 고성능 GPU 없이도 활용할 수 있다는 것이 특징.

## 2. 주요 솔루션(Task) 정리

| 솔루션 | 기능 | 대표 출력 |
|---|---|---|
| Hand Landmarker | 손 랜드마크(21개 관절 포인트) 검출 | 손가락 위치, 손 모양 |
| Gesture Recognizer | 손 모양을 기반으로 제스처 분류 | 엄지척, 브이, 주먹 등 |
| Face Detector | 얼굴 위치 검출 | 얼굴 바운딩 박스 |
| Face Landmarker | 얼굴 랜드마크(478개 포인트) + 표정 계수 | 눈/입/눈썹 움직임, 표정 |
| Pose Landmarker | 전신 관절(33개 포인트) 검출 | 자세, 스켈레톤 |
| Holistic | 얼굴+손+포즈 통합 검출 | 전신+얼굴+손 동시 추적 |
| Object Detector | 이미지 내 객체 탐지 | 사물 바운딩 박스 + 라벨 |
| Image Segmenter | 배경/전경 분리 | 셀피 세그멘테이션 마스크 |
| Face Stylizer | 얼굴 스타일 변환 | 캐리커처/애니메이션 얼굴 |
| Text/Audio Classifier | 텍스트·오디오 분류 | 감정, 언어 등 라벨 |

## 3. 활용 분야

### 3.1 게임 / 인터랙션 (제스처 기반 입력)
- 손동작(Hand Landmarker, Gesture Recognizer)으로 키보드/마우스 없이 게임 조작
- 예: 가위바위보, 공중 드로잉, 손가락으로 메뉴 선택
- 본 프로젝트(`gg_pywords_game`)와 연계 시, 키보드 입력 대신 **손가락 스펠링(수어 알파벳) 또는 특정 제스처로 정답 입력**하는 방식으로 확장 가능

### 3.2 헬스케어 / 피트니스
- Pose Landmarker로 운동 자세 분석 (스쿼트, 플랭크 자세 교정)
- 재활 훈련 시 관절 가동 범위 측정
- 낙상 감지, 자세 교정 알림 서비스

### 3.3 AR / 뷰티 / 콘텐츠 제작
- Face Landmarker 기반 AR 필터, 가상 메이크업, 아바타 립싱크
- Image Segmenter로 배경 교체(가상 배경, 화상회의 블러 처리)
- Face Stylizer로 캐릭터/이모지 생성

### 3.4 접근성 (Accessibility)
- 수어(수화) 인식 → 텍스트/음성 변환 보조 도구
- 손/눈 움직임만으로 컴퓨터를 조작하는 신체 장애인 보조 인터페이스

### 3.5 스마트홈 / IoT 제어
- 손 제스처로 조명, 가전제품 On/Off 제어
- 비접촉식 키오스크, 엘리베이터 버튼 조작 (위생/방역 목적)

### 3.6 보안 / 출입 관리
- Face Detector/Landmarker 기반 얼굴 인식 출입 통제
- 실시간 이상행동(포즈) 감지 CCTV 분석

### 3.7 교육 / 학습 도구
- 손가락 개수 세기로 유아 숫자 학습
- 발표 자세, 시선 처리 연습 피드백 도구
- 코딩 교육용 제스처 인식 실습 (본 프로젝트가 속한 커리큘럼의 `11_hand_tracking.py`, `12_hand_tracking.py` 실습 사례)

### 3.8 리테일 / 마케팅
- 매장 내 고객 동선/자세 분석
- 가상 피팅룸(AR로 옷/액세서리 착용 시뮬레이션)

### 3.9 방송 / 모션캡처
- 저비용 모션캡처(별도 슈트 없이 웹캠만으로 신체 추적)
- 버튜버(Virtual YouTuber) 실시간 표정·손동작 트래킹

## 4. 이 프로젝트에서의 확장 아이디어
현재 `gg_pywords_game`은 키보드 입력 기반 단어 맞추기 게임(pygame)이다.
MediaPipe Hand Landmarker/Gesture Recognizer를 도입하면 아래와 같은 확장이 가능하다.

- 손가락으로 알파벳 모양을 만들어 입력하는 "제스처 스펠링" 모드 추가
- 정답/오답 시 특정 제스처(엄지척/엑스)로 다음 문제로 넘어가기
- 웹캠으로 사용자의 반응 속도·자세를 함께 기록해 결과 CSV(`result/word_game_socre.csv`)에 추가 통계로 저장
